# Архитектура

Ядро — **8051** (подтверждено дизассемблером: `MOV DPTR,#imm; MOVX A,@DPTR` идиомы,
`LJMP`-векторы, `SETB/CLR`). В сервисном меню `Scaler-MCU: Novatek` — то есть это
системный MCU внутри скалера линейки NT68xxx.

## Банки кода: 2 MiB через P1[4:0]

Кодовое пространство 8051 — 64 KiB, а образ 2 MiB. Адресация — 32 банка по 64 KiB,
номер банка лежит в младших 5 битах порта P1:

```
банк = P1 & 0x1F
```

Старшие биты P1 при старте сохраняются, младшие обнуляются:

```
0x011F  MOV A,P1
0x0121  ANL A,#E0h
0x0123  MOV P1,A
```

## Межбанковый вызов

Вызов идёт через трамплин. Вызывающий:

```
MOV  DPTR,#<target>      ; адрес функции (в целевом банке)
LCALL <trampoline_for_bank_N>
```

Трамплин:

```
MOV A,P1                 ; текущий банк B
ANL A,#1Fh
SWAP A
RR A                     ; A = 8*B
PUSH ACC
MOV A,#2Ch
PUSH ACC                 ; адрес возврата = 0x2C{8*B} — стенд восстановления банка
PUSH DPL
PUSH DPH                 ; адрес цели
LJMP 0x2C00+8*N          ; стенд переключения на банк N
```

Стенд (по 8 байт на банк, `0x2C00 + 8*N`):

```
ORL P1,#1Fh
ANL P1,#<маска N>
RET                      ; → прыжок на target уже в банке N
```

При возврате из функции её `RET` попадает в стенд `0x2C{8*B}`, который ставит
исходный банк и возвращается к вызывающему.

Стенды **побайтово одинаковы во всех банках**, поэтому переходные значения P1
внутри `ORL/ANL` безвредны.

Верх банка (`0xFFF8`) — таблица, которую читают сразу после переключения
(`MOV DPTR,#0FFF8h; MOVC A,@A+DPTR`).

## Память

- IRAM 256 байт (моделировать нужно полностью: верхние 128 — не SFR);
- XDATA 64 KiB, окно `0xA000..0xBFFF` — рабочая RAM/структуры, `0xF000..0xFFFF` — регистры.

## Цикл сна

Конец загрузки — штатный power-save:

```
CLR IE.7                 ; все прерывания выключены
MOV DPTR,#0xF0D3
ORL A,#02h
MOVX @DPTR,A             ; запрос power-save
LCALL <wake routine>     ; читает 0xD511
JC  <проснулись>         ; выход только по carry
SJMP <снова в ожидание>
```

Wake-рутинна (`bank 2, 0x9131`) ставит бит `03h.5`, разбирает код в `0xD511` и
**всегда снимает бит** перед `RET`, из-за чего `carry` всегда 0. То есть
программно разбудить себя эта прошивка не может — пробуждение приходит по
аппаратной линии от второй подсистемы.

## Прерывания

Таймер 0 (`TMOD=0x21`, ISR по вектору `0x000B` → `0x3000`) обслуживает счётчики
времени и обмен. ISR завершается `RETI`, но обращения к банкам идут через
трамплины, поэтому в эмуляторе in-service latch нужно снимать и по обычному
`RET` — иначе после первого прерывания все следующие блокируются.

## Что не входит в образ

Прошивки остальных частей монитора: видеоблок/T-Con, PD-контроллер (Cypress CCG3),
USB-хаб (Realtek RTS5411). Они упоминаются в строках и в отладочных меню, но их
кода здесь нет.
